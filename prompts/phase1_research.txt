=====================
CRITICAL BUSINESS RULES
=====================

1. Standard email campaign discount codes usually expire in 7 days
2. Bin sale or holiday sale discount codes usually expire in 3 days
3. The true send date must NOT be taken directly from HubSpot send date fields
4. Instead, the send date must be parsed from the email campaign name
5. The discount code must also be parsed from the email campaign name
6. Email campaign naming convention is expected to follow:

YYYY-MM-DD - Producer/Topic - Campaign Type - Offer Value - Code

Examples:
- 2026-03-18 - 2010 Cos d'Estournel - PROD - 7% - CosD
- 2026-03-18 - Kapcsandy - PROD - 10% - KAP10
- 2026-03-18 - Bordeaux 1995 - EDU - None - None
- 2026-03-18 - Bordeaux Market - CONTENT - None - None

Definitions:
- Producer/Topic = Producer name (and vintage if applicable) or email topic
- Campaign Type:
  - PROD = product-first, sales-focused
  - EDU = educational but leads to shoppable pages
  - CONTENT = educational, links to blog only
- Offer Value = Discount value such as 5%, 7%, 10%, or “None”
- Code = Discount code or “None”
